# Image Processing Application — OOP Assignment 1

This repository contains our solution for **Assignment 1** in the **Object-Oriented Programming (OOP)** course. The application is developed in **C++** with a **Qt** graphical user interface and supports **18 image processing filters**.

## Overview
- Load and save images directly through an interactive desktop interface.
- Apply **18 image processing filters** and preview the changes.
- Built as a team assignment combining C++ image manipulation logic with a Qt GUI.

## Tech Stack
- **Language:** C++
- **GUI Framework:** Qt
- **Build System:** CMake

## How to Run
Open `CMakeLists.txt` in **Qt Creator** (or build using CMake), configure the kit, and run the application.
